One app, rewritten as I learned

Siddur One has been rebuilt every time I learned a better way to build it, so it's a pretty good record of how I got here.

  1. 2014

    Java, in Eclipse

    When I started, I didn't know how to connect a button in the XML to the code. It took me another year to figure out what JSON was. It was called Ice Cream Siddur, and it only ran on Android.

  2. 2016

    Beezy Works Studios

    I gave myself a studio name, because it was a great name. The app moved to Android Studio and kept growing, with home screen widgets, shortcuts, and support for different prayer traditions. It went through seven major versions and kept getting updates until 2023.

  3. 2020

    React Native

    After a couple of years of React Native at work, I rewrote it from scratch so one codebase could run on both iPhone and Android. This time I designed the architecture up front instead of letting it grow on its own.

  4. 2026

    Expo, with AI

    I started it again with AI as my main tool. I make the decisions and the AI writes most of the code. In a few months it moved to Expo, got a web version and a shared design system, and gained two sibling apps.
